# Dogfooding: self-check before «готово»

После **любой UI-правки** перед словом «готово»:

1. Открыть URL через Playwright MCP
2. Прокликать изменённый элемент и ключевой сценарий рядом
3. Проверить desktop и mobile (viewport 375 px)
4. Приложить скриншот к финальному сообщению
5. Если что-то сломалось — починить и повторить (максимум 2 итерации, потом стоп + описание блокера)
